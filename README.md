AegisNet 🛡️

AI-Powered Network Intrusion Detection & Automated Threat Mitigation System

AegisNet is a network security prototype designed to monitor network traffic, analyze packet-level data, identify suspicious activity, and provide security insights through a web dashboard.

🔹 Current Features

* Packet capture using Scapy
* Network traffic analysis using Python
* Source IP and protocol-based analysis
* Rule-based suspicious traffic detection
* REST API using Flask
* Interactive web dashboard using HTML, CSS & JavaScript
* CORS support using Flask-CORS

🔹 System Pipeline

Network Traffic → Scapy → CSV Dataset → Traffic Analyzer → Flask API → Web Dashboard

🔹 Tech Stack

Python | Scapy | Flask | Flask-CORS | HTML | CSS | JavaScript | CSV | Git | GitHub

🔹 Future Scope

* Real-time traffic monitoring
* CNN-BiLSTM based intrusion detection
* DDoS, port scanning & brute-force detection
* Explainable AI using SHAP/LIME
* Real-time threat alerts
* Automated firewall-based mitigation

Status: Working prototype — AI/ML-based detection and automated mitigation are planned for future development.
